# Tetris en Python

Juego de Tetris desarrollado con Python y Pygame como proyecto para portafolio.

## Caracteristicas

- Piezas clasicas de Tetris.
- Movimiento con teclado y rotacion.
- Caida automatica de las piezas.
- Vista previa de la siguiente pieza.
- Eliminacion de lineas y sistema de puntuacion.
- Pantalla de Game Over.

## Requisitos

- Python 3.10 o superior.
- Pygame.

## Instalacion

```bash
git clone https://github.com/jciasenza/Tetris.git
cd tetris-python
python -m venv .venv

# Windows PowerShell
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

## Ejecucion

```bash
python main.py
```

## Controles

| Tecla | Accion |
| --- | --- |
| Flecha izquierda | Mover pieza a la izquierda |
| Flecha derecha | Mover pieza a la derecha |
| Flecha abajo | Acelerar la caida |
| Flecha arriba | Rotar pieza |
| X | Salir de la pantalla de Game Over |
